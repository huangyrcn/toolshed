# Toolshed

Personal Claude Code plugin marketplace.

## Plugins

| Plugin | Description |
|--------|-------------|
| [paper-skills](https://github.com/huangyrcn/paper-skills) | Academic paper workflow: search, acquire, read notes, repo discovery, PDF-to-markdown. |
| [citation-double-check](https://github.com/huangyrcn/citation-double-check) | Verify academic citations: parse references, fetch evidence, check claims, suggest repairs. |
| [web-kit](https://github.com/huangyrcn/web-kit) | Lightweight web search + scraping + download: SearxNG metasearch, crawl4ai rendering, CDP file download. |
| [web-kit](https://github.com/huangyrcn/web-kit) | Lightweight web search + scraping + download: SearxNG metasearch, crawl4ai rendering, CDP file download. |

## Install

```
/plugin marketplace add huangyrcn/toolshed
/plugin install paper-skills@toolshed
```
